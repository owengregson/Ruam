# Specialist 3: data, state, constants, and lifetime boundaries

Independent round, 2026-10-09. This proposal assumes the charter's fully informed, editable-artifact attacker and an offline core. None of the representations below contains a secret. Success means a measured increase in reusable recovery cost under equivalent protection coverage; unchanged-artifact reuse remains possible.

## Findings from the actual implementations

Main centralizes integer stack encoding in `buildStackEncodingHelpers`, emitted once even with per-function shielding: [`1fb1a61`, assembler.ts:341–344, 627–630](https://github.com/owengregson/Ruam/blob/1fb1a61/packages/ruam/src/ruamvm/assembler.ts#L627). Masked stack values still become ordinary values at operations and calls. The decode cache also creates a complete instruction array on compatible configurations; constants already live in cleartext `U.c` ([CLAUDE.md:155–156](https://github.com/owengregson/Ruam/blob/1fb1a61/CLAUDE.md#L155)). This gives an attacker reusable semantic collection points rather than forcing analysis of individual application computations.

The September WIP improves structural ownership but keeps explicit value structure. `f7f52c8:packages/ruam/src/isogloss/runtime/regional-lowering-types.ts:51–82` (local-only snapshot) exposes active registers, stack slots, scopes and completion state. `regional-artifact-emitter.ts:1145–1195` allocates regional frame bindings; `:3369–3391` copies live values between layouts. Regional binding cells have a recognizable array schema, with the current value in slot 1, initialization in slot 5, and optional mapped-argument accessors in slots 3/4 (`f7f52c8:packages/ruam/src/isogloss/runtime/regional-binding-lowering.ts:105–178` (local-only snapshot)). Random field names do not change this recoverability. `opaqueRegionalStringExpression` reconstructs strings; `regionalStringConstant` still supplies literals to semantic lowering.

PR5 also demonstrates why module and key boundaries must be an architectural contract: `vmShielding` returns before applying external/cohort/consumer folds ([transform.ts:213–276](https://github.com/owengregson/Ruam/blob/30f4563/packages/ruam/src/transform.ts#L213)). An isolated reproduction produced correct results under `max` with wrong/missing external secrets and without a declared provider. Splitting files or scattering an embedded key is not a new trust boundary.

## S3-A: eliminate recoverable intermediates through consumer specialization

**Mechanism.** Build a use-def and escape graph after semantic lowering. Inside a proven effect-free region, fuse producers into their consumers and remove virtual stack/register storage. Share expensive subexpressions only within that region; duplicate cheap expressions across mutually exclusive successors under a strict size budget. Specialize private calls by their actual consumers when recursion and code growth permit. The output computes the same semantics without first materializing an enumerable semantic frame. This is compiler deforestation and specialization, not XOR masking presented as secrecy.

A private integer pipeline can become a fused consumer expression; a value that reaches a callback, getter, exception, closure, or suspension receives an explicit live binding. Arbitrary JS arithmetic must preserve `-0`, NaN, infinities, BigInt exceptions and evaluation order. Do not assume associativity or reorder coercions. Only proven primitive operations qualify: `+`, property access and conversions may invoke user code. No whole-source coverage claim depends on an operation qualifying for this optimization.

**Attacker consequence and bypass.** A stack-decoder hook no longer reveals every intermediate. However, an artifact-aware attacker can normalize expressions into SSA and instrument every producer. Cleaner optimized expressions may actually be easier to decompile. Thus this is a candidate only when combined with the control-domain's genuine multi-operation regions, not a standalone protection headline.

**Interface/cost.** Consume `RegionPlan`, `EffectOrder`, `ValueUseGraph`, `EscapeClass` and owner-only semantic provenance. Return region AST plus a live-out contract, never a shipped node-to-value map. Budget at most 15% emitted-byte growth for duplication; no object allocation per primitive operation. Generic JS values remain exact native values at required boundaries.

**Experiment/kill.** Compare identical region partitioning with versus without specialization on arithmetic, parsing and callback-heavy fixtures. Give the attacker compiler source and many builds. Measure automated SSA recovery, required instrumentation locations, held-out behavioral equivalence, CPU and human/tool setup separately. Kill as a protection component if one generic normalization pass restores the same semantic graph with under 2× attack CPU or if recovered quality improves. Retain independently useful optimizations without security credit.

## S3-B: liveness-owned activations and explicit effect boundaries

**Mechanism.** Replace one shared mutable frame/cell schema with compiler-owned activation layouts containing only values that survive each effect or suspension. Non-escaping locals remain native lexical bindings. Allocate shared cells only for actual aliasing: captured mutable bindings, module live bindings, or mapped arguments. Each continuation owns its live captures; dead references are released where observationally permissible. Never decode or snapshot all registers merely to enter a region. Layout specialization follows semantic liveness, not random padding.

Every host call, coercion, getter/setter, proxy trap, iterator step, yield and await has an ordered boundary contract. Commit visible state before a reentrant call; preserve the active invocation separately from nested invocations. Carry completion kind/value and pending finally state explicitly. A thrown object is rethrown unchanged. Recursion cannot borrow singleton scratch slots. Native suspension machinery should retain scheduling behavior; introducing promises or microtasks for protection would change semantics.

**Identity consequences.** Preserve actual object/function references across the ABI. Do not insert blanket proxies: `===`, WeakMap keys, private brands, `instanceof`, receiver-sensitive built-ins and identity of thrown values forbid transparent replacement. Shared closure cells and module exports remain one logical binding. Do not promise secure erasure in a garbage-collected JS engine or alter WeakRef-observable reachability casually. Reflection and `Function.prototype.toString` require an explicit product contract shared with the semantics specialist.

**Attacker consequence and bypass.** This removes the convenient complete-frame heap dump and universal cell reader, but debugger/heap access and generated-AST capture analysis can recover distributed state. Suspending generators offers especially convenient capture snapshots. The intended hurdle is stitching lifetimes and aliases, not preventing observation.

**Interface/cost.** Define build-side `ActivationShape`, `LiveSet`, `AliasCellId`, `CompletionEdge`, `BoundaryPlan` and `ModuleCellContract`; emit specialized code, not a general tagged-value service. Boundary plans enumerate receiver, arguments, coercions, callbacks and exception edges in exact order. Reuse shapes only where it does not recreate a universal frame. Track allocations, retained bytes, GC time, recursion depth and suspension count. Zero extra allocations on nonescaping synchronous straight-line paths is the target.

**Experiment/kill.** Use mutually recursive closures, generator `throw/return`, async reentry, Proxy getters, mapped arguments, cyclic module bindings and identity-sensitive WeakMaps. Compare full-frame recovery from one heap snapshot and a compiler-aware capture extractor. Any semantic mismatch vetoes the candidate. If universal capture extraction reconstructs the original state graph at the same normalized cost, keep liveness savings but reject the protection claim.

## S3-C: specialize internal constants into their consumers

**Mechanism.** Classify constants by use. Replace internal-only finite string decisions with specialized decision DAGs or UTF-16 transducers; fold private enum/string tables into the branches and computations that consume them. The original string or table is never reconstructed wholesale when the semantics only require a decision. This differs from encoding a pool then calling a decoder. Escaping values, property keys, RegExp sources and host-visible arguments materialize faithfully at their existing semantic boundary; they receive no secrecy claim.

Eligibility must prove primitive inputs and closed-world use. Preserve coercion timing, UTF-16 code-unit behavior, lone surrogates, `-0`/NaN distinctions and exact thrown exceptions. Reject specialization of reflective/mutable tables or regex features without a proven equivalent lowering. Private object identity must not be replaced just because its fields look constant.

**Attacker consequence and bypass.** Pool dumping fails for transformed constants. Static symbolic execution, DAG minimization, enumeration and chosen-input learning may recover them more cheaply. The prior learnable custody experiment is a warning: a complicated representation of a small finite function is not meaningful resistance.

**Interface/cost and experiment.** Consume the same use/escape/effect graph and a `ConstantUsePolicy`; return a specialized region and explicit materialization sites. Cap code growth and benchmark worst-case input length. Test string validators, finite routing maps and parser tables against ordinary encoded pools, using both intrinsic logging and static/black-box reconstruction. Kill if a general extractor recovers constants and behavior within 2× baseline effort, or if the transformed lookup is slower than a declared product budget.

## Recommendation

Make S3-B's liveness, aliasing and boundary contracts shared infrastructure; do not sell them as proven defense. Prototype S3-C first and S3-A jointly with regional control lowering. Retain coverage/correctness infrastructure and source-map hygiene; replace global decoded caches and universal codecs where experiments justify it. Key custody, services, trusted hardware and remote secrets are excluded entirely by the user’s strict offline JavaScript constraint. None of these components independently establishes a stronger offline protection system; the attack experiments decide whether they deserve inclusion.
